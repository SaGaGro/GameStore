System Requirements — GameStore Platform
ภาพรวมระบบ
ระบบขายเกมออนไลน์ รองรับการซื้อ-ขายเกม Digital ระหว่าง Publisher กับ Customer โดยมี Admin คอยดูแลระบบ

Roles และสิทธิ์การใช้งาน

RoleId 1 — SuperAdmin
จัดการทุกอย่างในระบบ อนุมัติ/ปฏิเสธ Publisher Request จัดการ User ทุกคน จัดการ Campaign ระดับแพลตฟอร์ม

RoleId 2 — Admin
ดูแลระบบเบื้องต้น อนุมัติเกมที่ Publisher ส่งมา ดูรายงาน จัดการโปรโมชั่น

RoleId 3 — Publisher (เจ้าของเกม/ค่ายเกม)
เพิ่ม/แก้ไขเกมของตัวเอง สร้างโปรโมชั่น ดูรายได้และรีวิว

RoleId 4 — Customer
ผู้ใช้ทั่วไป ซื้อเกม สะสมแต้ม รีวิว จัดการ Wishlist และยื่นขอเป็น Publisher ได้

โปรโมชั่น

FestivalSale — ลดราคาช่วงเทศกาล
Publisher ตั้งส่วนลด % และช่วงวันเวลา ราคาจะลดอัตโนมัติในช่วงนั้น

FreeGame — แจกฟรีช่วงเวลา
กำหนดวันเริ่ม-สิ้นสุด ผู้ใช้กด Claim เพื่อเพิ่มเกมเข้า Library โดยไม่เสียค่าใช้จ่าย

Early Bird — Pre-order ลดราคา
เกมที่ยังไม่วางจำหน่าย (ReleaseDate อยู่ในอนาคต) และมี DiscountPercent กำหนดไว้ จะแสดงราคาลดพิเศษก่อนวางจำหน่าย

Points — ระบบสะสมแต้ม
ซื้อทุก ฿10 ได้ 1 แต้ม และ 1 แต้มมีมูลค่า ฿0.50 สามารถนำแต้มมาหักลดราคาตอน Checkout ได้

SeriesDiscount — ลดภาคอื่นใน Series
ถ้ามีเกมใน Series เดียวกันอยู่ใน Library แล้ว จะได้รับส่วนลด 30% สำหรับภาคอื่นในซีรีส์นั้น

Campaign — ส่วนลดระดับแพลตฟอร์ม
Admin สร้าง Campaign เช่น Summer Sale หรือ Songkran Festival และเลือกเกมที่เข้าร่วม ส่วนลดจะใช้งานอัตโนมัติในช่วงเวลาที่กำหนด

ฟีเจอร์หลัก Customer
ค้นหาและกรองเกมตามชื่อ หมวดหมู่ ราคา และคะแนน ซื้อเกมและชำระเงิน ใช้แต้มสะสมลดราคาตอน Checkout จัดการ Wishlist และเพิ่มทั้งหมดลงตะกร้าได้ รีวิวเกมที่ซื้อแล้วได้ 1 ครั้งต่อเกม ดูประวัติแต้มสะสม และยื่นขอเป็น Publisher

ฟีเจอร์หลัก Publisher
เพิ่มเกมใหม่พร้อมอัปโหลดรูปปกและรอ Admin อนุมัติก่อนเผยแพร่ แก้ไขและลบเกมของตัวเอง สร้างโปรโมชั่น ดูรายได้ ยอดขาย คะแนนเฉลี่ย และรีวิวจากผู้เล่น

ฟีเจอร์หลัก Admin
อนุมัติหรือปฏิเสธเกมที่ Publisher ส่งมา จัดการ Campaign ระดับแพลตฟอร์ม และอนุมัติ Publisher Request

ฟีเจอร์หลัก SuperAdmin
ทำได้ทุกอย่างที่ Admin ทำได้ บวกกับจัดการ User ทุกคน ระงับบัญชี และเปลี่ยน Role

Tech Stack
ASP.NET Core MVC (C#) แบ่งเป็น Areas ตาม Role ใช้ MySQL ผ่าน EF Core (Pomelo) Auth แบบ Session-based เก็บ UserId, RoleId, DisplayName รูปปกเกม upload เก็บใน /wwwroot/uploads/games/
